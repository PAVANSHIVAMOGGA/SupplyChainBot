# ABC Corporation — Quality Control Checklist: Incoming Goods

This checklist is used during Step 4 (Quality Spot-Check) of SOP-WH-IN-001 and applies to all incoming raw materials, components, and finished goods.

## Pre-Inspection

- [ ] Confirm PO number and supplier match the shipment documentation
- [ ] Confirm lot/batch number is legible and recorded
- [ ] Confirm product matches PO specification (SKU, description, unit of measure)

## Visual Inspection

- [ ] No visible external damage to packaging
- [ ] No signs of moisture damage, crushing, or contamination
- [ ] Labeling is correct: product name, lot number, expiry/manufacture date (where applicable), country of origin
- [ ] Packaging integrity intact (seals unbroken, shrink wrap undamaged)

## Dimensional / Specification Check (Sample-Based)

- [ ] Sample units measured against spec sheet tolerances (±2% unless otherwise specified in the product spec)
- [ ] Weight check within tolerance for weight-sensitive items
- [ ] Color/finish matches approved reference sample (for cosmetic-critical parts)

## Functional Check (Where Applicable)

- [ ] Electrical/mechanical components: basic functional test performed per component-specific test protocol
- [ ] Batteries/electronics: voltage or charge-level check within spec

## Documentation

- [ ] Certificate of Analysis (CoA) present for chemical/regulated materials
- [ ] Material Safety Data Sheet (MSDS) on file for hazardous materials
- [ ] Country-of-origin documentation present for customs-flagged categories

## Disposition

Based on inspection results, mark ONE:

- [ ] **PASS** — Release to putaway
- [ ] **CONDITIONAL PASS** — Release with Corrective Action Plan filed against supplier
- [ ] **QUALITY HOLD** — Segregate, notify Procurement + Supplier Quality within 2 business hours
- [ ] **REJECT** — Return to supplier, initiate RMA per Return & Damage Policy

## Sampling Plan Reference

| Lot Size | Sample Size | Acceptance Number (Ac) | Rejection Number (Re) |
|---|---|---|---|
| Up to 500 units | 20 | 1 | 2 |
| 501 – 3,200 units | 32 | 2 | 3 |
| 3,201 – 10,000 units | 50 | 3 | 4 |
| Above 10,000 units | 80 | 5 | 6 |

Sampling plan follows ABC's adaptation of ANSI/ASQ Z1.4 general inspection level II.
